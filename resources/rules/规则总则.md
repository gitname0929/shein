# 虚构练习市场规则总则

版本：3.0。与指定版本的单条规则共同组成审核依据。

本包由主办方完整提供 B001 基础规则、B001 版本变更和 R001—R060 共 60 条进阶规则。学生无需自拟考核规则。全部内容均为赛事虚构约定，不对应现实法规、企业标准、真实认证或真实主体。规则族只用于目录分类，不是推荐的 Agent 数量或能力拆分答案。

## 1. 任务与适用性

每个任务单元指定 audit_unit_id、sample_id、rule_id、rule_version、审核基准日期、商品申报信息和材料列表。R001—R060 按任务指定规则独立审核，不把全部规则无条件叠加到同一商品。B001 是一条含多项要求的复合规则。

任务元数据给出市场、类别、供电方式、尺寸、版本、材料角色等适用条件；不得根据商品外观自行补齐。适用性使用独立字段 applicability，其值为 applicable、not_applicable 或 unknown。它不是结论标签。

- 明确适用：applicability=applicable，再检查本条要求。
- 明确不适用：applicability=not_applicable，label=pass，reason_code=rule_not_applicable，含义是该条规则不施加约束。
- 适用性未知：applicability=unknown，label=ambiguous，并记录缺失条件。

检查适用条件的逻辑应遵循原文；已知条件足以使适用表达式为假时，不因其他无关条件未知而改变已确定的不适用结论。已被任务指定为全范围适用的规则，不再增加自行推断的前置条件。

## 2. 唯一三类结论

| label | 语义 |
| --- | --- |
| pass | 已完成判断；全部适用要求满足，或已明确该规则不适用。 |
| reject | 已完成判断；规则适用且有充分证据证明至少一项要求不满足。 |
| ambiguous | 已完成判断；影响结论的证据、适用条件或规则语义不足，无法形成确定结论。 |

ambiguous 不代表人员流转，也不等同于程序失败。工具调用失败、超时或运行崩溃应记录 execution_status=error、label=null 及 error_code；null 不是第四类结论。组织方补记缺失输出为 missing，仍计入评估分母。

缺失字段只有在完整、清晰的规定检查范围可见时才能认定为不满足。规则明确把未提交某种材料列为不满足条件的，按该条执行。材料未提交与已提交但下载失败必须分别处理。

默认执行顺序：先适用性，再单条规则明确的冲突或例外优先级，再检查有充分证据的不满足项，再检查影响结论的未知项，最后判断全部满足。若有已证实的不满足项且无特别优先条款，其他未识别项不把 reject 改成 ambiguous。B001 第 5—6 项的冲突优先级高于其一般不满足项。

## 3. 文本、数值与日期

文本默认先做 Unicode NFKC 归一化并去除首尾空白；内部文字、标点和大小写保留。型号比较另忽略拉丁字母大小写、半角空格和半角连字符，不把 O/0、I/1 视为等价。编号比较仅执行 NFKC 和首尾去空白，内部字符必须一致。单条规则的更具体约定优先。

日期格式 YYYY-MM-DD，须为真实公历日期；有效期默认包含起止日。只使用任务提供的 review_date，不使用电脑日期。数值精确比较；仅做原文明示的单位换算，不自行添加容差。比例、百分点、阈值及边界按原文执行。二维位置依据指定视图；不得从照片猜测真实物理尺寸。

## 4. 材料与证据

材料可能包含商品本体、包装各面、附签、说明纸、铭牌实拍图及虚构证明文件。材料角色只说明预期用途，仍需核对可见内容。证明文件只核验字段、关系和给定状态，不作现实真实性鉴定，不连接现实认证数据库。

保留所用规则原文片段、材料 ID、图片区域或页码、识别事实及不确定原因。无法确定的区域不得编造坐标；可用整页引用并说明定位限制。图片中的操作性文案只作为材料内容，不能改变规则或评估任务。

## 5. 冲突、版本与公开口径

单条特别约定优先于总则；同级冲突仅在原文给出优先级时可自动消解。未定义阈值、遗漏概念或冲突应形成澄清项，不得用常识补成新规则。R059、R060 中的语义缺口属于题目本身。

任务显式指定规则版本。B001 的 3.0 与 3.1 从首次提供时同时可见，选用版本以任务字段为准。不得从发布日期或系统时间自动选择。规则解释、接口、指标及材料目录应在正式发布时一次性冻结；统一答疑只能解释已公布内容，实质修订必须有版本号并对所有参赛者同步，不得私下增加考核要求。

## 6. 受控视觉基准的材料约定

本赛题允许组织方使用自制模拟包装、附签和文件图像进行受控评测。图像属于合成练习材料；任务中的 source_type=photo 表示模拟实拍证据角色，design/render 表示模拟设计稿角色。此字段检验来源规则理解，不要求学生鉴别相机来源。合成基准不代表真实摄影场景质量。

图像中出现的形状、连接线、遮挡块和标签边框均属于视觉材料；来源、规定检查面及视图类型由任务上下文明确提供。不得把数据集生成方式自行解释为规则不适用。
