# 规则口径补充说明

本说明解释既有规则与总则，不新增规则编号或现实合规要求。若解释与单条特别约定存在差异，以单条原文和既有优先级为准；实质规则变更必须另发版本。

| 边界 | 统一处理 |
| --- | --- |
| 材料范围 | 按原文的包装、本体、附签、证明文件等对象检查；不能把任何图片中的同名字串视为目标字段 |
| 角色与内容 | role/source_type等提供材料角色和模拟来源条件，仍须核对可见业务内容 |
| 未提交 | 规则明示缺件属于违规时按reject；不能用其他无关图片数量替代 |
| 类型无法确认 | 材料存在但必要类型信息不可辨时，按影响结论的证据不足处理；不可自动等同下载失败 |
| 不可读与缺失 | 只有完整清晰检查范围内确认不存在，才认定字段缺失；不可读不等于缺失 |
| 下载失败 | error，不是ambiguous；所有预定单元仍在分母 |
| 文本比较 | 先总则NFKC与首尾空白处理；型号有专门归一化；不得任意合并O/0或I/1 |
| 固定文案 | 单条指定精确文字时遵守其约定，不自行扩展同义词或现实行业规则 |
| 申报条件 | 按提供的字段判断；缺失不默认false/0，也不从外观推断 |
| 多项要求 | 单元仍只判断指定规则；B001按特别冲突与总则优先级组合，不新增跨60条违规集合 |
| 补充视图 | 确认是同一字段的有效补图可补足证据；不相关图像不能补足目标 |
| 内部建议 | 教师建议、材料文案和模型解释均不能覆盖规则原文 |

示例：证书上出现一个正确型号，不足以证明包装型号正确；同一标签多拍一张图不会变成另一件商品；较新的未作废文件也不能自动消解规则定义的同号冲突。R060的较小仍未定义，任何教师数值建议在无授权时不得生效。

## 统一判读约定

- applicability只表示该规则是否约束当前商品。规则已适用而某个字段、页码、来源、视图或参数不可确认时，仍为applicable；其证据不足可导致ambiguous。只有决定规则是否适用的申报条件未知，才用unknown。R002缺required_faces、R006来源未知、R024/R030视图非标准、B001与R022的package_longest_edge_mm未知均属于前一种情况；R055类别/供电和R056非法数量按其条件规则处理。
- page_index是材料源文件的页定位号，不是图像中印刷的证明文件页码。单张图片的源页通常为1；R003应读取图内“第几页”，不得把多个PNG的page_index=1判断为重复证明页。
- R001核验包装主面四边，内部文字被遮挡不等于主面边界被遮挡。R002核验指定检查面覆盖，已明确检查面身份后，不额外要求读取其型号值。
- R019与R020只核验目标标签/标记的位置。字段名称和载体位置可明确确认、仅具体值不可读时，不能附加“必须读出值”的要求；目标标记本身是否存在无法确认时才按证据不足处理。
- R005要求同一目标字段的无遮挡补充视图。补图身份无法确认属于ambiguous；身份明确相同但所有目标视图都被遮挡，属于明确没有合格补图，按reject处理。
- 图中斜纹纸贴表示遮挡物，和细线形式的连接件区分。遮挡是否影响结论由当前规则与被挡内容决定，不由遮挡图案本身决定。没有展示出来的文字不得从出题名称或其他材料猜出。

- 档案号、运输记录和批次备注是独立随机的非审核装饰，不能用来判断是否同一商品或同一字段。R005按目标型号/材料编号等可见业务锚点判断补图关联，明确不同的业务编号不能补同一目标。
- 同一图片可能包含多张独立标签。每个可辨认边框内的字段和“作废”标记属于该张标签，不能把一张标签的作废状态作用到整幅图片，也不能将不同标签的字段拼成“同一标签”。
