# 插件接口与运行约定

标准Python适配签名为evaluate(inputs, outputs, references, context) -> dict。四个参数均为JSON可表示的对象：前三个是记录列表，context为字典，至少包含schema_version="1.3.1"和purpose。inputs是审核任务；outputs是对应预测；references仅为公开自评标签或组织方专用插件夹具，不提供正式880单元真值给学生插件。

CLI入口仍为evaluate --plugin PLUGIN --inputs INPUT_JSONL --outputs PREDICTIONS_JSONL --references REFERENCES_JSONL --out REPORT_JSON。最小样例的PLUGIN使用module:function，例如plugins:conclusion。项目内可按manifest把插件ID映射到相同签名，非Python实现通过CLI适配即可。

报告字段为plugin_id、plugin_version、input_schema_version、metrics、diagnostics、errors。metrics是可JSON序列化的字典，数值须有限；无法计算用null并给出原因。diagnostics和errors是数组，错误不吞掉、不伪造成高分。公开插件输出契约给出常见指标，正式总分仍由组织方评分器计算。

插件逐次在独立进程中执行，输入通过序列化副本提供且视为只读，运行时限由调用方按环境设置，退出异常或非法输出单独记录。一个插件失败不阻断其他插件；输入变更应作为故障报告。组织方可按需在无网络容器中运行插件并只读挂载文件。最小样例plugin_runner.py仅提供进程隔离、超时和对象变更检测，本地开发模式不声称具备容器网络隔离。

04_最小对接样例提供结论质量插件和证据结构插件。后者只检查引用结构，不自动核验视觉事实语义；它展示接口，不代表完成比赛中完整证据插件的功能验收。参赛者需实现实际证据内容评估和原定插件要求。

样例可通过PLUGIN_TIMEOUT_SECONDS设置本次插件调用时限；未设置时不附加样例自身的时限，不对应赛事预算。
