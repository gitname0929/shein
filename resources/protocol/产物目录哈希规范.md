# 产物目录哈希规范

组织方trust.py与学生校验工具使用同一artifact_hash.py。推荐直接调用，不自行实现另一套“等价”算法。

文件摘要是文件原始字节的SHA256小写十六进制，不做换行或Unicode转换。目录递归枚举全部普通文件（包括隐藏文件），忽略目录条目和空目录；路径相对指定目录，以/分隔。符号链接、特殊文件及超过1GiB的单文件拒绝。文件修改时间和权限不进入摘要。

建立字典“相对路径字符串→文件摘要”。用UTF-8编码JSON，ensure_ascii=False、sort_keys=True、separators=(',',':')、allow_nan=False，不附加换行；对这段字节做SHA256。没有默认忽略列表，.DS_Store或缓存文件也会改变摘要，应在构建前清理。

artifact_manifest.json格式为{"entries":[{"rule_id":"B001","rule_version":"3.0","artifact_version":"my-v1","path":"engine","sha256":"目录或文件摘要"}]}。entries每个rule_id+rule_version唯一；多个规则可以引用同一共享engine。相对路径不得越界。不要把entry指向包含manifest自身的根目录，否则产生自引用；将可执行能力放在engine子目录，先算engine摘要，再写manifest。

清单全部写完后，组织方计算整个产物根目录的摘要，此时包含manifest本身。entry.sha256与根目录摘要是两个不同对象，不可混用。feedback.base_artifact_sha256使用整个baseline产物根目录摘要。

运行python3 校验工具/artifact_hash.py PATH即可得到摘要。固定字节测试向量见hash_fixture及hash_fixture_expected.json；学生和组织方均须得到其中的同一结果。
