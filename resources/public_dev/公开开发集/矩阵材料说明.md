# 组件对应矩阵教学

R050要求组件编号与型号逐项对应，组件表可以是明示列表，也可以是带图例的矩阵。矩阵行是组件编号，列是型号；黑点表示该行组件与该列型号存在一条记录，空白表示没有该记录，斜纹表示对应格不可读。按图中图例还原记录后，再使用同一条公开规则核对，不新增业务要求。

四个独立3×3例子分别演示完整匹配、错配、决定性未知，以及已知错配与其他未知同时存在。后一种仍判reject。示例索引见矩阵教学索引.json，图片在inputs/assets，标签在references/audit_gold.jsonl，参考输出在reference_predictions.jsonl。正式材料可能使用不同的行列顺序与更大规模；不能按元数据数组顺序猜黑点的位置。

标注任务可以明确指定一个行列交叉格。此时bbox圈该格，value用任务要求的有记录/无记录，格子不可读时为null且status为unreadable。审核label仍针对整个任务，不由被选格子的状态单独决定。
