# Supervisor acceptance gates

These are review gates, not claims of passing implementation. Worker reports alone do not close them.

## Foundation

- Model equality preserves O/0 and I/1; ASCII-space/hyphen/case normalization is model-only.
- Source pages are exact JSON integers. Duplicate keys/nonfinite values/symlink and traversal paths are rejected.
- A complete clear empty field differs from unreadability, and both differ from a failed tool.
- Known-false applicability conjunct short circuits irrelevant unknowns.
- Same-label requirements never combine fields across separate labels.
- B001 90 mm attached tag changes permitted carrier between 3.0 and 3.1; 80/100 endpoints are strict.
- B001 active-source conflict overrides ordinary mismatch; no conflict means proven violation precedes unknown.
- NeedEvidence drives an actual observation action; tool failures cannot become ambiguous.
- Checkpoints and retries preserve one final output per original task and immutable attempt history.

## Rules and artifacts

- All 62 ID/version pairs load actual plans; no generic fallback that passes unsupported rules.
- Every advanced rule has at least a meaningful semantic check; R059/R060 retain valid non-conflict branches.
- R005 requires same-business-field identity, not decorative/archive ID matching.
- R019/R020 location checks do not require readable values if mark identity is clear.
- R024/R030 geometry uses specified view; equality endpoints pass when authorized.
- R037-R042 use exact permitted conversion and rule-specific tolerances.
- R048 withdrawal before issue date is ambiguous; otherwise review on withdrawal date rejects.
- R050 and R052 use keyed relationships, not independent sets.
- R057 needs one complete alternative; R058 uses production date, not review date.
- Source hashes, manifest entries and capability dependency hashes bind actual execution.
- Incremental impact includes transitive dependencies; unrelated artifacts can retain hashes.

## Inference and annotation

- Actual image extraction transcribes source content and layout before deterministic judgment.
- Crops map back to source coordinates; PDFs preserve original page identity.
- No reference/gold/sample-ID-based decision path.
- Annotated value preserves transcription; label is whole-unit decision.
- Public data results are measured and reported; mocks are clearly separate.

## Evaluation and iteration

- A/U/Q and comparison use applicability plus label plus validity; denominator is frozen.
- Duplicates, missing, invalid version, extra IDs, error and empty sets follow official contracts.
- Evidence structure and visual-content support are distinct.
- Plugin exceptions/timeouts/input modification do not change predictions or other plugins.
- Feedback source is not authority; candidate never overwrites baseline.
- Local checks never pretend to establish hidden protection/final scores.

## Product and release

- All 16 product tasks exercise real persisted services, not static mocked counters.
- A restart preserves IDs, active version and pending/finished work.
- UI and CLI share implementation and actual artifact identity.
- A clean checkout works without the original parent material package.
- No keys, gateway tokens, runtime logs or private files enter Git.
- Only reviewed commits are pushed; initial remote is empty and no force push is needed.
